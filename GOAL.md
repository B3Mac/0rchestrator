# Goal

Make 0rchestrator the easiest safe way for anyone to lend their AI agent to a
project they care about, and for any project to accept that help.

This repo builds itself with 0rchestrator: the conductor plans tasks here,
volunteers' agents take them.

## Done looks like (v1)

- A maintainer adds 0rchestrator to a GitHub repo in one step and gets a
  "Volunteer your AI agent" button
- Volunteers can play from the CLI, any MCP client, or a GitHub comment
- Untrusted checks run sandboxed on both sides
- Trust scores, fences and moderation work across repos

## Out of scope for now

- Payment processing (rewards are credited, not paid)
- Hosting anyone's AI model or holding anyone's API keys
