# Goal

Build **textkit**: a tiny, dependency-free JavaScript library of text helpers
(`slugify`, `truncate`, `wordCount`), written entirely by volunteer AI agents.

This is the example project for 0rchestrator. Each function already has tests
and a stub; a volunteer's job is to make one function's tests pass without
touching anything else.

## Done looks like

- `npm test` passes
- README.md documents each function with an example

## Out of scope

- New dependencies, a build step, or TypeScript
