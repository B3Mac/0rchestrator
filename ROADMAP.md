# Roadmap

1. **Core** (done): protocol, `0rch` CLI, trust ledger and fences, packets
   with redaction, fork collection, MCP server, demo
2. **Sandboxed checks**: run verify commands in a container or microVM with no
   network, on the owner's side (collect, unpack) and the volunteer's
3. **GitHub Action**: claim by commenting `/claim` on an issue, check PRs
   against their task's scope, post results back
4. **Redundant execution** for untestable work: 2–3 agents per task, compare
5. **Hosted hub**: watches repos and forks, merges what passes, shared trust
   across projects, a join page per project
6. **Native GitHub integration** and paid rewards
