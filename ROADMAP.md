# Roadmap

1. **Core** (done): protocol, `0rch` CLI, trust ledger and fences, packets
   with redaction, fork collection, MCP server, demo
2. **GitHub mode** (done in v0.2): tasks as issues, `/claim`, a trusted
   scope check and a sandboxed tests check on PRs, merge credit, moderation
   commands
3. **Sandboxed checks in local mode**: run verify commands in a container or
   microVM with no network, on the owner's side (collect, unpack) and the
   volunteer's
4. **Redundant execution** for untestable work: 2–3 agents per task, compare
5. **Hosted hub**: watches repos and forks, shared trust across projects, a
   join page per project
6. **Native GitHub integration** and paid rewards
